# Donexus charity demo template

Static responsive prototype with two demo modes:

- `/?type=church`
- `/?type=masjid`

**Demo only:** not affiliated with any specific charity; checkout disabled and no payment data collected.

## Roadmap
1. Ingest private lead spreadsheet in a secure pipeline (never commit contacts to this public repo).
2. Verify official charity website, classification, logo, palette, images and fundraising content.
3. Generate reviewed per-charity configuration, without implying endorsement.
4. QA accessibility, mobile rendering, accuracy and links.
5. Publish individual Vercel previews after approval.
6. Integrate charity-owned Stripe Connect/checkout with webhook verification before enabling payments.

All real charity data and secrets must remain outside this repository until permissions and privacy are reviewed.
